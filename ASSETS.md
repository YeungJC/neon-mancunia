# Audio and visual asset provenance

- `public/voice/rain-0.mp3`: “Make it dance.” Generated through ElevenLabs TTS by `scripts/gen-rain-vocals.ts`.
- `public/voice/rain-1.mp3`: “Mint. Absolutely mint.” Generated through the same workflow.
- `public/voice/rain-2.mp3`: “Turn it up.” Generated through the same workflow.
- These three samples use the configured project voice and `eleven_flash_v2_5`. The API key remains server-side. The phrase pads play full samples; the rhythmic loop gates them to two beats with short fades.
- Existing `public/voice/line-*.mp3` and `public/sfx/*.mp3` are generated by the existing ElevenLabs scripts. Text and sound prompts are in the repository. Provider terms apply to generated assets; the code license does not replace those terms.
- Rain puddles, impact rings, falling beads, and the city are procedural geometry/shaders. No assets were copied from the reference design repositories for this feature.
- `public/fonts/orbitron-*.woff` is Orbitron; its SIL Open Font License is included beside the files.
